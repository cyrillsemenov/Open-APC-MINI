3. Short Scripting Guide

The firmware runs a tiny integer stack VM (LUA1 bytecode, up to 4,096 bytes) directly on the APC Mini's STM32F102 MCU. Your script compiles right here in the browser (via Rust + full_moon WASM) and uploads over USB-MIDI SysEx in milliseconds — either into live RAM for instant iteration or into Flash (0x08008000) so it survives power cycles.

Quick Starter Example

function init()
    pos = 0
    set_tempo(120)
end

function on_grid(x, y, z)
    if z == 1 then
        note_on(0, 48 + x + (7 - y) * 5, 100)
        led(x, y, 15)
    else
        note_off(0, 48 + x + (7 - y) * 5)
        led(x, y, 0)
    end
    return 1 -- consume press (return 0 to pass through)
end

function on_fader(idx, val, hires)
    if idx == 8 then
        set_tempo(30 + ((16383 - hires) >> 7))
    end
end

function on_tick(step)
    led(pos, 8, 0)
    pos = (pos + 1) & 7
    led(pos, 8, 1)
end

Callbacks

Scripts are driven by up to five top-level callback functions (custom helper functions are not supported):

Callback When It Runs & Arguments
init() Runs once on upload, reset, or VM enable. Top-level statements also act as init if init() is omitted.
on_tick(step) Cooperative coroutine called every tempo tick (step increments 0, 1, 2…). Alias: tick.
on_grid(x, y, z) Grid pad press (z=1) / release (z=0), x,y = 0..7. Return 1 to consume the event; 0 passes it through to MIDI / serialosc. Aliases: g.key, grid_key.
on_fader(idx, val, hires) Fader moved: idx = 0..8 (8 is Master), val = 0..127, hires = 0..16383. Alias: fader_move.
on_button(group, idx, z) Round & Shift buttons: group=1 Track 1..8 (idx=0..7), group=2 Scene 1..8 (idx=0..7), group=3 SHIFT (idx=0). Return 1 to consume. Alias: button.

Coordinates, Overlay & LEDs

  • Grid Coordinates: x = 0..7 (left to right), y = 0..7 (top to bottom — Monome convention).
  • Non-Destructive Overlay: Grid LEDs sit on an overlay layer above Ableton / serialosc. Setting led(x, y, 0) clears your overlay and restores whatever host LED is underneath.
  • Varibright Levels: 1..15 maps through the active palette on Config / Debug (Default Palette 0: 1..5 Green, 6..10 Yellow, 11..15 Red; 16 = 1-bit ON).
  • Round LEDs: led(x, 8, state) controls Track LEDs 1..8 and led(8, y, state) controls Scene LEDs 1..8 (0 = off, 1 = solid, 2 = blink).

Built-in Functions

Function Description
led(x, y, val) Set pad overlay (0..16) or round LED (y=8 Track, x=8 Scene). Aliases: g:led, g.led.
led_all(val) Fill all 64 pad overlays with val (0..16). Aliases: g:all, g.all.
host_led(x, y) Read host LED level (0..16) from serialosc or MIDI underneath.
note_on(ch, note, vel) Send USB-MIDI Note On (ch 0..15, note/vel 0..127). Also sends serialosc key if note < 64.
note_off(ch, note) Send USB-MIDI Note Off (and serialosc key-up if note < 64).
cc(ch, num, val) Send 7-bit USB-MIDI Control Change (0..127).
cc14(ch, cc, val14) Send 14-bit MSB+LSB MIDI CC pair (cc = 0..31, val14 = 0..16383).
pitch_bend(ch, val14) Send 14-bit USB-MIDI Pitch Bend (0..16383).
grid_key(x, y, z) Emit synthetic key down (z=1) / up (z=0) to MIDI and serialosc. Aliases: trigger_key, mext_key.
key_pulse(x, y, ms) Non-blocking key down + automatic key up after ms (up to 4000 ms, 8 slots).
tilt(s, x, y, z) Send Monome mext tilt report (sensor 0..3). Alias: mext_tilt.
fader(idx) / fader_hires(idx) Read fader 0..8 as 7-bit (0..127) or 14-bit (0..16383; alias fader14).
shift() Returns 1 while SHIFT is held, else 0.
set_tempo(ms) Set on_tick interval in ms (clamped 10..2000, default 55 ms).
yield() / sleep_ms(ms) Suspend on_tick until next loop turn or for ms (up to 4000 ms).
rand(max) Pseudo-random integer in 0 .. max - 1. Alias: math.random.
abs(x), min(a,b), max(a,b) Integer math helpers (also under math.*).
life_step() Fast C-accelerated 8×8 toroidal Game of Life step from mem[0..63] + host_led into mem[64..127]; returns alive count.

Language Subset & Limits

  • Integer-Only VM: Locals and stack values are signed 32-bit integers; globals and shared array mem[0..511] store signed 16-bit integers. Two-dimensional indexing like grid[y][x] maps automatically to mem[y * 8 + x].
  • Control Flow & Operators: Supports if/elseif/else, while, numeric for (constant step), do..end, return, arithmetic (+ - * / // %), bitwise (& | ~ << >>), and comparisons (== ~= < <= > >=). Note: and / or evaluate both sides eagerly.
  • Not Supported: Floating-point math, strings, dynamic tables/closures, break, repeat..until, and user-defined helper functions.
  • Resource Caps: Max 64 globals, 64 locals per callback, 4,096 B bytecode image. Long on_tick loops are sliced (256 opcodes per main-loop turn, up to 131,072 ops/tick) so USB-MIDI and LED scanning stay responsive.
